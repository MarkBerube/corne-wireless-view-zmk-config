# Working on the display artwork

Use this repository for the right-side Corge bitmap and its Zephyr module. Route keyboard layout requests to [MarkBerube/zmk-config-corne](https://github.com/MarkBerube/zmk-config-corne). The local keymap serves the standalone display build.

Follow the [artwork integration guide](README.md) to update the consuming repository’s pin and verify the firmware artifact after artwork changes.
